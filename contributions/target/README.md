# Target packs (contributions)

Pull requests put target packs here: `contribution-target-<id>-<version>.zip`, exported with
`llmcf zoo export target <id> --author "<name>" --pr` or uploaded here in the browser. Only pack files of at most
5 MB; the check workflow runs `llm-cli zoo verify` on each. After review the maintainer moves an accepted pack to
[packs/target](../../packs/target) and adds it to the signed index. How to contribute: [README](../../README.md#contributing).

Hier legen Pull Requests Target-Packs ab; nach dem Review wandert ein angenommenes Pack nach `packs/target/` und in den signierten Index ([README_DE](../../README_DE.md#beitragen)).
