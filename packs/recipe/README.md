# Published recipe packs

The maintainer moves accepted recipe packs here from [contributions/recipe](../../contributions/recipe); the entries of the signed
index point to these files (`https://raw.githubusercontent.com/Smilez1985/Edge-LLM-Knowledge-Base/main/packs/recipe/<file>`)
and pin their size and sha256. A published file is never changed or replaced: a new version is a new file. Pull
requests do not add files here. Steps: [MAINTAINERS.md](../../MAINTAINERS.md).

Hier liegen die veröffentlichten Rezept-Packs, auf die der signierte Index zeigt; eine veröffentlichte Datei wird nie geändert, eine neue Version ist eine neue Datei ([MAINTAINERS_DE.md](../../MAINTAINERS_DE.md)).
