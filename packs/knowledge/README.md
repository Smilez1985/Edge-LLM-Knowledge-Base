# Published knowledge packs

The maintainer moves accepted knowledge packs here from [contributions/knowledge](../../contributions/knowledge); the entries of the signed
index point to these files (`https://raw.githubusercontent.com/Smilez1985/Edge-LLM-Knowledge-Base/main/packs/knowledge/<file>`)
and pin their size and sha256. A published file is never changed or replaced: a new version is a new file. Pull
requests do not add files here. Steps: [MAINTAINERS.md](../../MAINTAINERS.md).

Hier liegen die veröffentlichten Wissens-Packs, auf die der signierte Index zeigt; eine veröffentlichte Datei wird nie geändert, eine neue Version ist eine neue Datei ([MAINTAINERS_DE.md](../../MAINTAINERS_DE.md)).
